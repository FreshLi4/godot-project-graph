  - 将引用边视为无向布局关系。
  - 按连通分量和连接度选择根。
  - 通过 BFS 图距离分配同心层级。

- 隐藏 Godot 内置 Arrange 按钮，避免用户再次得到纵向分层布局。
- 新增 `Ignore…` 对话框：
  - 默认排除 `res://addons/**`、`res://.godot/**` 与 `res://.import/**`。
  - 非 `res://` 的引擎资源维持原有边界，不进入扫描。
  - 支持项目相对路径、`*` / `?` 通配和 `/**` 目录前缀。
  - 自定义模式保存到 `user://freshli4_project_graph/settings.cfg`。
  - 在目录遍历与依赖解析阶段同时剪枝，避免依赖边把忽略节点重新带回图谱。
